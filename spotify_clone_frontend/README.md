# spotify_clone_frontend

React (Vite) Spotify-clone style frontend with:
- Sidebar + Topbar + routed main content
- Persistent bottom audio player (mini player supported)
- Mock data (songs, albums, artists, playlists)
- Recently played (localStorage)
- Drag & drop playlist reordering
- Skeleton UI for lazy-loaded pages

## Environment variables
Uses `.env` (already provided). Key ones:
- `REACT_APP_PORT`
- `REACT_APP_BACKEND_URL`
- `REACT_APP_API_BASE`
- `REACT_APP_FRONTEND_URL`

## Run
```bash
npm install
npm run dev
```
